Features (Pro)

  • SurvivalStats: hunger/thirst drain, starvation damage, regeneration, died signal
  • DayNightClock: time of day, phases, day_started, light_level(); demo day/night tint and music crossfade
  • Inventory with slot and stack limits, atomic remove_all, set_count, take_all
  • RecipeBook: data-driven recipes with optional crafting-station tag
  • BaseBuilder + StructureDef: grid placement with "near X" rules, storage containers, crafting stations, craft_near
  • Gatherable resource nodes with hits, depletion and respawn
  • SaveGame: versioned JSON save, migration hooks, atomic write; WorldNodes makes spawned children savable
  • Pure-logic systems with manual tick/advance – everything testable headless
  • Playable demo: top-down movement with collision, 4-direction walk animation, HUD need bars, inventory grid, crafting panel, chest UI, mouse placement with green/red ghost
  • All demo content (items, recipes, structures, resource nodes, sounds, needs) is data in content.json

Not included

  • No combat, enemies or night raids
  • No temperature, tool durability, farming or tech tree
  • 1-cell structures, no rotation; removal does not refund
  • No multiplayer; saves are plain JSON
  • Tested headless on Godot 4.7.2 (plus scripted headless-Chrome run of the web export); real browsers/devices not tested

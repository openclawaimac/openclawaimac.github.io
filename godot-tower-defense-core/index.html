Features (Pro)

  • TDContent: towers, enemies, waves and the map in one JSON file, with validate()
  • TDMap: cell grid with path / blocked / buildable cells, world ↔ cell conversion, validation
  • TDEnemy: follows a polyline path; hp, speed, armor (flat reduction), slow, bounty, leak damage, flying flag
  • TDTower: hitscan towers with FIRST / LAST / STRONGEST / CLOSEST targeting, splash, slow, air/ground filter, DPS readout
  • Data-driven upgrade levels and sell refund (70% of gold spent)
  • TDWaveSpawner: data-driven waves with per-wave HP scaling, wave-clear bonus, next-wave preview, placement rules, sell, win/lose signals
  • TDEconomy: gold, lives and a defeated signal
  • Headless-friendly: auto_tick = false + advance(delta) drives the whole game from tests
  • Playable demo: 4 towers, 6 enemy types (incl. flyers and a boss), 12 waves; build bar, hover/upgrade panel with targeting toggle, wave preview, win/lose screen
  • Demo juice: recoil, muzzle flash, explosions, floating numbers; camera pan/zoom; 1x/2x/3x speed, pause, mute
  • Kenney CC0 sprites, sfx and jingles, "Battle Theme A" (CC0) music; HTML5 web demo

Not included

  • One fixed path per map (no maze building / pathfinding); single map in the demo
  • Hitscan towers – no projectile physics
  • No save/load, meta-progression, hero units or abilities
  • No multiplayer
  • Tested headless on Godot 4.7.2 (plus scripted headless-Chrome run of the web export); real browsers/devices not tested

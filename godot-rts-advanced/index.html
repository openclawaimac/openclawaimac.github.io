Features (Pro)

  • Selection: drag box with live unit count, click, shift-add, ctrl-toggle, control groups, type counts
  • Orders and formations: box and line slots facing the direction of travel, crossing-free slot assignment, per-unit reserved destinations so groups never pile up
  • Terrain with plateaus, ramps and cliffs: height, normals, line of sight, render mesh with cliff walls
  • Cliff-aware A* pathfinding with slope cost, building footprints, crowd cost and an occupancy grid
  • Combat: weapons with damage, penetration, accuracy, range and interval; directional light/heavy cover, height advantage, front/side/rear armour, suppression meter; seeded RNG
  • Production: many producers per team, unit requirements, population cap, pause/repeat, rally points, refund when a producer dies; squad templates built from a selection
  • Harvesting: resource fields with depletion/regrowth and worker slots, gather → carry → unload cycle
  • Construction: placement preview and checks (flat ground, occupancy, build radius), paid build sites, cancel/sell refunds, team power with low-power slowdown
  • Fog of war per team (unexplored / explored / visible), height-aware sight, shared vision
  • AI opponent with Easy/Normal/Hard, build order, army mix and attack/retreat – acts only through the player systems (no map hacks)
  • Save/load: versioned JSON snapshot with checksum, tamper and version checks; minimap with fog, markers, click to jump and right-click to command
  • Camera, key rebinding with conflict check, localization with live language switch (en/fr)
  • Playable skirmish demo: 5 unit types, 6 buildings, full HUD and minimap; unit and building catalogs are data, so new unit types need no code

Not included

  • One skirmish map and one AI opponent in the demo; no campaign or map editor
  • No multiplayer / networking
  • Compatibility renderer: no real-time shadows in the demo (blob shadows and baked AO instead); switch to Forward+ for real shadows
  • Tested headless on Godot 4.7.2 (plus scripted headless-Chrome run of the web export); real browsers/devices not tested

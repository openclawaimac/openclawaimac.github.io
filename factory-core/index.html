Features (Pro)

  • Flow-graph belt simulation with gap-based belt lines (no per-item physics); two-lane belts with side-loading and underground tunnels
  • Machines with input/output buffers and recipes, Mk1–Mk3 tiers (speed/power per mille), recipe switching
  • Splitters with filter and fair mergers
  • Power grid with generators and brownout
  • Throughput stats and a heuristic bottleneck finder with colour overlay (idle/working/starved/blocked/no power)
  • Deterministic fixed tick – FactorySim.step(n) runs fully headless
  • Grid build mode: data-driven hotbar, ghost preview (valid/invalid), rotation, drag-placed belt lines with auto-connect, removal with refund and cost hooks
  • Undo/redo (restores items of removed nodes), blueprints: capture, rotate, paste, serialize
  • Items, recipes and buildables as Resources or loaded from JSON, with FactoryDB.validate()
  • JSON save/load with migrations
  • Camera pan/zoom and a 120x80 demo map with iron/copper ore fields (drills need ore)
  • JSON build scripts for starter layouts; reskin via skin.json + PNGs
  • Demo chain: ore → plates → gears, wire → circuits → motors (8 items, 6 recipes, 15 buildables)

Not included

  • 1x1 buildables only; no inserters/arms, fluids, trains, robots or logic network
  • One power network per sim; no poles, fuel or accumulators
  • Bottleneck finder is a heuristic, not full flow analysis
  • Tested headless on Godot 4.7.2 (plus scripted headless-Chrome run of the web build); real browsers/devices not tested
